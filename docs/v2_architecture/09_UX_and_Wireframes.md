# MatPilot V2 User Experience & UI Wireframes

## 1. UX Navigation Hierarchy
The platform UX is designed as a "Hub and Spoke" model.

- **Hub (Workspace Dashboard)**: High-level overview of the research project. Shows recently uploaded files, active experiments across all instruments, and a unified action button to "Enter Instrument".
- **Spoke (Instrument Home)**: E.g., `/instruments/ftir`. A dashboard specific to FTIR. Shows a table of FTIR experiments.
- **Node (Experiment Page)**: E.g., `/instruments/ftir/123`. The actual scientific software environment. The screen is maximized for data visualization and parameter control.

## 2. Global UI Principles
- **Dark Mode Native**: Scientific software is often used for long hours; dark mode with vibrant accent colors (purple for FTIR, green for XRD) reduces eye strain and looks premium.
- **High-Density Information**: Researchers prefer seeing all parameters without scrolling. Use collapsible sidebars for controls and maximize the central canvas for charts.
- **State Persistence**: If a user tweaks a baseline and leaves, the state must be preserved upon return.

## 3. Wireframes

### Wireframe 1: Workspace Dashboard (The Hub)
**Layout**:
- **Left Sidebar**: Navigation (Dashboard, Files, Reports, Settings).
- **Header**: Workspace Name, Project Selector.
- **Main Content**:
  - Top: "Launch Instrument" Carousel (Cards for XRD, FTIR, Raman, UV-Vis).
  - Middle: Global Recent Activity Feed (e.g., "FTIR baseline corrected", "XRD Rietveld complete").
  - Bottom: Unified Report Generator button.

### Wireframe 2: FTIR Instrument Home (The Spoke)
**Layout**:
- **Left Sidebar**: Collapsed (Back to Workspace).
- **Header**: "FTIR Spectroscopy Environment" + Accent Color Branding.
- **Main Content**:
  - Top: "New FTIR Experiment" button (Upload area).
  - Middle: Data Table. Columns: Experiment Name, Spectra Range, Peaks Found, Date, Status.
  - Clicking a row opens the Experiment Page.

### Wireframe 3: FTIR Experiment Page (The Node)
**Layout**:
- **Left Sidebar (30% width)**: Workflow accordion.
  1. Pre-Processing (Baseline method dropdown, Smoothing slider).
  2. Peak Detection (Prominence slider).
  3. Analysis (Database match trigger).
- **Main Canvas (70% width)**: 
  - Large Recharts/Plotly line chart. X-axis reversed (4000-400).
  - Interactive nodes for baseline anchoring.
- **Bottom Panel**: Draggable up. Contains the AI Interpretation chat stream and the tabular peak list.

### Wireframe 4: Workspace Report Page
**Layout**:
- **Header**: Export to PDF/Word.
- **Main Canvas**: A scrollable document layout.
  - Section 1: Executive Summary (Generated by Global Correlation AI).
  - Section 2: XRD Results (Diffractogram + Phase Table).
  - Section 3: FTIR Results (Spectrum + Functional Groups).
  - Section 4: AI Cross-Analysis reasoning.
