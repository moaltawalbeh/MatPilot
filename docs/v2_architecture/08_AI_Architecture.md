# MatPilot V2 AI Architecture

## 1. Core Paradigm: Multi-Agent Scientific Reasoning
MatPilot V2 abandons the "one chatbot fits all" approach. The AI architecture consists of highly specialized, loosely coupled intelligent agents, each pre-prompted and equipped with domain-specific knowledge bases and validation tools.

## 2. Agent Modules
- **XRD AI Scientist**: Trained on crystallography logic. Validates Rietveld R-factors. Explains phase purity and preferred orientation.
- **FTIR AI Scientist**: Trained on molecular vibrations. Interprets fingerprint regions, explains overlapping functional groups, and assigns confidence to library matches.
- **Raman AI Scientist**: Trained on solid-state physics. Differentiates polymorphs and provides reasoning for peak broadening (e.g., amorphization, strain).
- **UV-Vis AI Scientist**: Trained on semiconductor physics. Translates band gap values into material properties (e.g., photocatalytic viability).
- **Global Correlation AI**: Resides at the Workspace level. Ingests the JSON outputs of the specialized AI scientists to draw cross-technique conclusions.

## 3. Data Flow for AI Reasoning
1. **Computation & Validation**: Raw data is processed by the Scientific Computation Engine, and the output is rigidly checked by the `Scientific Validation Layer`.
2. **Context Assembly**: The backend serializes the *validated results* (not raw spectra, due to token limits) into structured JSON. Example: Peak list, intensities, library match scores, and a strict `confidence_score` generated by the Validation Layer.
3. **Prompt Construction**: The JSON is injected into a strict prompt template enforcing the "Experienced Materials Scientist" persona.
4. **Execution**: The LLM processes the data, reasoning through the results step-by-step.
5. **Output Parsing**: The response is streamed back to the UI in sections (Findings, Reasoning, Confidence, Uncertainty, Next Steps).

## 4. Guardrails & Uncertainty
The AI must never hallucinate certainty. Prompt engineering enforces strict rules:
- Must explicitly state confidence levels (e.g., "High confidence for O-H stretch, but the fingerprint region is ambiguous").
- Must provide physical reasoning for assignments.
- Must recommend complementary techniques (e.g., "Confirm this XRD phase with Raman spectroscopy").
